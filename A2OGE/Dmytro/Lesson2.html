Task 9 · Grammar Rules

Should / Shouldn't

✅ SHOULD = It is a GOOD idea!

You + should + sleep.

(Тебе следует спать.)

❌ SHOULDN'T = It is a BAD idea!

You + shouldn't + eat candy.

(Тебе не следует есть конфеты.)
